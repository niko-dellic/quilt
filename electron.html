DESKTOP DEMO

Quilt for Electron

The vanilla and React demos, packaged as a desktop application. Includes pane layouts, themes, workspace JSON, and popout windows. Runs offline; Node.js is not required.

USAGE

Running the demo

Use the header to switch between vanilla and React. A popped-out pane opens in a separate window; closing that window returns it to the main layout. Saved workspaces restore with all panes docked.

macOS Open the DMG and drag Quilt Demo into Applications.

Windows Open the downloaded EXE to launch the portable app.

Ubuntu / Debian Open the DEB with your software installer, then launch Quilt Demo.

First launch: unsigned demo builds

These builds have no trusted developer certificate and are not notarized. macOS builds use an ad-hoc signature. Your OS may show an unidentified-developer warning.

On macOS, you may need to approve Quilt Demo in System Settings → Privacy & Security after first opening it. On Windows, the warning may offer More info → Run anyway. Managed devices may block unsigned apps.
