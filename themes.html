Your theme file

quilt-theme.json 

          

          

            
Use it in your app

            
Save the exported file beside your app code. With a JSON-capable bundler:

            
import theme from './quilt-theme.json';

// Vanilla
workspace.setTheme(theme);

// React
<Layout store={store} components={components} theme={theme} />

            

              The file contains theme tokens only. Layouts, fonts, and stylesheets stay app-owned.
              CSS variable references need the matching variables in your application.
