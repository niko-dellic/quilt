# Quilt

A TypeScript library for split panes, tab groups, and popout windows. Quilt provides a framework-independent layout model, a DOM renderer, and React bindings.

Your application owns the pane content and data. Quilt manages workspace layout, interactions, and persistence through JSON configuration.
