# Examples

## Copy a small starter

The starters use published package imports and keep application data outside pane
views. Each has its own README and commands.

- [Vanilla starter](https://github.com/niko-dellic/quilt/tree/main/examples/vanilla)
- [React starter](https://github.com/niko-dellic/quilt/tree/main/examples/react)
- [Electron starter](https://github.com/niko-dellic/quilt/tree/main/examples/electron)

See the [examples index](https://github.com/niko-dellic/quilt/tree/main/examples)
for exact setup instructions and the distinction between a starter and the full demo.

## Explore the showcase

- [Vanilla demo](https://quilt-layouts.vercel.app/vanilla.html)
- [React demo](https://quilt-layouts.vercel.app/react.html)
- [Desktop downloads](https://quilt-layouts.vercel.app/electron.html)

The Theming tab lets you customize tokens and export `quilt-theme.json`.
Layout JSON saves the workspace configuration separately. The demos are larger
applications; start with the minimal examples when integrating Quilt.
